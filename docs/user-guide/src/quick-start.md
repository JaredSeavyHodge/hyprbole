# Quick Start

This page covers the basic controls you need after the first-login checklist.

## Open Apps

- Press `SUPER + SPACE` to open the app launcher.
- Press `SUPER + ALT + SPACE` to open the Hyprbole menu.
- Press `SUPER + RETURN` to open a terminal.
- Press `SUPER + SHIFT + F` to open the file manager.
- Press `SUPER + SHIFT + B` to open the browser.
- Press `SUPER + V` to open clipboard history.

The launcher is the fastest way to find applications. The Hyprbole menu is where common system actions, tools, themes, installs, and help entries live.

## Use Workspaces

- Click a workspace number on the top-left bar to switch to it.
- Press `SUPER + 1..0` to switch workspaces from the keyboard.
- Press `SUPER + SHIFT + 1..0` to move the focused window to another workspace.

Workspace `0` means workspace `10`.

## Manage Windows

| Keybind | Action |
| --- | --- |
| `SUPER + Q` | Close focused window |
| `SUPER + T` | Toggle floating window |
| `SUPER + F` | Toggle fullscreen |
| `SUPER + H/J/K/L` | Move focus left/down/up/right |
| `SUPER + S` | Toggle scratchpad workspace |
| `SUPER + left mouse drag` | Move window |
| `SUPER + right mouse drag` | Resize window |

## Use The Top Bar

The left side shows the Hyprbole logo and workspaces.

The center shows date/time and Hyprbole status indicators, including update and health alerts.

The right side shows tray icons and quick access for idle mode, notifications, Bluetooth, audio, battery, and system monitor tools. When SwayNC has notifications, the bell shows a count; left-click opens the notification panel and right-click dismisses all notifications.

## Lock, Logout, Reboot

Open the Hyprbole menu with `SUPER + ALT + SPACE`, then use the power/session entries.

Common shortcuts:

| Keybind | Action |
| --- | --- |
| `SUPER + SHIFT + L` | Lock screen |
| `SUPER + CTRL + L` | Log out |

## Screenshots And Recording

| Keybind | Action |
| --- | --- |
| `Print` | Region screenshot |
| `Shift + Print` | Fullscreen screenshot |
| `SUPER + SHIFT + R` | Toggle region recording |
| `SUPER + SHIFT + ALT + R` | Toggle screen recording |

Screenshots open in Satty for annotation when appropriate.

## Get Help

Open `Help`, `Keybinds` from the Hyprbole menu for the full shortcut list, or run `hb keybinds`.

If something looks broken, incomplete, or misconfigured, open [Troubleshooting](troubleshooting.md).
